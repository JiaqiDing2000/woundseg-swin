Fig. S5. Unnormalized confusion matrix for the internal wound dataset. Cells show absolute pixel counts for seed 1004, retaining the representative run specified in the manuscript. This run evaluates 2,293,760 pixels from the 35-image internal development evaluation subset after ground-truth-assisted 256 × 256 ROI preprocessing. Rows denote reference labels and columns denote predictions; no row or column normalization is applied. Counts are abbreviated as k (×10³ pixels); exact integer counts are provided in the CSV.
